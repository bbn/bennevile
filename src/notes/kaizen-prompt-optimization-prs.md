Kaizen is adjacent but on-topic for software-factory review: it optimizes prompts from traces/feedback and can open GitHub/GitLab/Bitbucket PRs so prompt changes get the same review discipline as code.

## Why it matters for code review

Prompts and agent skills are now production artifacts. If they bypass PR review, your “AI review stack” has a hole. Kaizen’s auto-PR path is a concrete pattern for closing it.
