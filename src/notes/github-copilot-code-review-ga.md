The GA note is short, but it marks the moment GitHub put a first-party AI reviewer into the default path for paid Copilot seats—auto via repo rules or on demand.

## Why it matters for code review

Distribution beats feature lists. Once CCR is one click away on github.com, third-party reviewers must win on signal, customization, or cross-host support—not on “AI review exists.”
