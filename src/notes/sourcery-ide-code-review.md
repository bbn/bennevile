Sourcery pushes review left into the IDE Review tab while also adding PR summaries and reviewer guides on GitHub—another early IDE+PR hybrid.

## Why it matters for code review

Pre-commit review changes author behavior more than reviewer behavior. Track whether IDE review reduces PR comment load or simply duplicates it.
