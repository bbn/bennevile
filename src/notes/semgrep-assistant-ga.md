Semgrep Assistant’s GA story is AppSec workflow AI: triage, FP identification, rule writing/management, and remediation help around Semgrep findings—not a generalist PR reviewer.

## Why it matters for code review

Security review ≠ bug review. Assistant-style tools change the backlog economics for SAST. Later Semgrep AI rebrands aside, this GA date is the clean 2024 milestone for AI-assisted Semgrep operations.
