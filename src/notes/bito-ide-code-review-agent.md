Bito documents an IDE-native `@codereview` agent for staged/local changes before PRs, with a note that Git-linked context materially improves depth.

## Why it matters for code review

Pre-PR agents only help if context is real. “Basic code understanding” without repo history is a different product from cross-file, ticket-aware review—Bito at least says the quiet part.
