Qodo 2.4 pushes review past single-repo diffs: Cross Repo Review for dependent services, Rules Miner from historical reviews, and Skill Review Standards as governed entities. That is the enterprise governance layer catching up to agent volume.

## Why it matters for code review

Monorepo/multi-repo breakage is where human reviewers already struggle. If AI review stays file-local, it will miss the same class of incidents. Cross-repo context is becoming a differentiator worth testing, not a buzzword.
