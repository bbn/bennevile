Sourcery’s GA note is an early data point in the AI PR-review wave: free for OSS, inline comments instead of drive-by refactor PRs, complexity review, and bot-PR filtering.

## Why it matters for code review

Useful baseline for how far the category has moved since 2024. Many later “agentic” features still solve the same UX problem Sourcery hit early: don’t open noisy secondary PRs—comment on the author’s PR.
