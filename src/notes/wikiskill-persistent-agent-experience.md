Agent “skills” packages are trending: specialized workflows that extend what a coding agent can do. WikiSkill targets the missing half—insights from skill discovery usually stay trapped in optimization histories and never become systematic reusable knowledge.

The paper’s framing is skill evolution: compile experience into persistent knowledge so later runs do not rediscover the same lessons. That is closer to institutional memory than to a one-off prompt tip.

## Why it matters for code review

Review findings are a high-value experience stream. If accepted review comments never become skills, checklists, or agent rules, every PR starts from zero. WikiSkill is useful mental model for turning review outcomes into durable agent capabilities.
