Google’s I/O note makes Gemini Code Assist for GitHub generally available as a PR review agent alongside the IDE assistant, on Gemini 2.5.

## Why it matters for code review

Another hyperscaler-native reviewer with a free wedge. Useful default for GCP-centric orgs; later consumer-GitHub sunset notes (2026) mean you should confirm whether you’re on consumer vs enterprise paths.
