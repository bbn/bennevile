The companion repo to the OpenCodeReview paper: hybrid deterministic + LLM agent CLI, line-level comments, multi-language rules, and installable skills/plugins for popular coding agents.

## Why it matters for code review

Rare open, large-scale industrial review stack you can actually run. Useful for baselines and for teams that want self-hosted review without buying another SaaS seat.
