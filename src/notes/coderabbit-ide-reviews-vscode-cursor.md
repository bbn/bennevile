CodeRabbit’s IDE extension announcement makes the pre-PR vs PR-review split explicit: free, lightweight reviews in the editor to catch bugs before a PR exists, and a heavier PR reviewer with more context for production workflows.

## Why it matters for code review

Shift-left review changes the metrics. IDE reviews optimize for speed and early catch; PR reviews optimize for codebase context and merge gating. Treat them as different products even when they share a brand.
