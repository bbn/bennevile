Qodo argues code review needs dedicated models/agents, not reused codegen prompts, and introduces Qodo 2.0 with a multi-agent setup plus a 580-defect / 100-PR benchmark. Self-published F1 numbers are not gospel, but the precision–recall framing is the right scoreboard.

## Why it matters for code review

The field is converging on “don’t optimize for comment count.” Qodo’s public stance—recall first, then precision via judges/specialists—is a useful foil to vendors who only quote thumbs-up rates.
