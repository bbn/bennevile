Survey cut: AI is everywhere for individual tasks, rare as a governed engineering system of work (88% say they need one; 19% have one). Code volume rises; bottlenecks before and after implementation get worse.

Review fails when intent, standards, and decision history live in tickets, docs, and Slack while the PR arrives naked. Only 15% of engineers (25% of leaders) are very confident they could reconstruct AI-assisted reasoning six months later. Agents need a system of record they write back into—what they did, context used, decisions, unresolved questions.

Three moves: make intent/context explicit before generation; extend AI into testing/observability; make agent work traceable. Internal note: Teamwork Graph context improved answer quality while cutting tokens.

## Why it matters for code review

Review scales when context travels with the change. Without a shared work system, peer review stays a human reconstruction tax that cannot keep up with agent throughput.
